# Ribbon key tips

In a part document, press `Alt`, then `M` to show the 3D Model command key tips.
When the ribbon uses compact groups or is docked at the side, press `K` to open
Sketch, `C` to open Create, or `Y` to open Modify. Press `S`, `K` to start a
sketch, or `E`, `X` to open Extrude when it is available.

Press `Alt` to hide the key tips. Press `Escape` to close an open group.

With top-level key tips visible, press an arrow key to rotate the model view.
Opposite arrow keys rotate it back.

Click a visible model face to dismiss the key tips and select the face. Use
**Zoom Selected** in the toolbar beside the face to frame it in the view. Click
empty viewport space to clear the selection.
