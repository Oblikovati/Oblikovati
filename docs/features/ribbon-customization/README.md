# Ribbon customization

A part document can open Customize User Commands from a ribbon panel title or
from the Tools tab. Add commands to a tab's User Commands panel, reorder them,
and choose their size and text display on each row. New commands start with
Large and Text clear. A removed command keeps its options if it is added back
before Apply. Double-click a command to transfer it
between the lists. Select a row and use Shift with Up or Down to select
multiple rows for transfer. Apply keeps the dialog open; OK applies
and closes it. Cancel and Escape discard edits since the last Apply. Escape
closes an open target or category list before it closes the dialog. A target
remains marked as changed until Apply, OK, or Cancel, even if an edit returns
the list to its earlier state.

The command list includes sketch geometry, constraint, and dimension commands.
Other commands remain limited to the entries shown in the dialog. Some
commands are unavailable until their host operations exist. Settings last for
the current application session. Keyboard and marking-menu customization,
import and export, other document types, and persistence remain open work.
