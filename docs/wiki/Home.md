# Oblikovati Wiki

Welcome to the Oblikovati user wiki.

- **[[Command Manual]]** — every command the Command Window accepts, grouped by document
  type and area, with a description and usage example. This page is generated automatically
  from the application's built-in command vocabulary and republished on every merge.
- **[[Lua Scripting]]** — how to automate the model with embedded Lua: the `oblikovati`
  host table, the sandbox, runnable examples, and a generated reference of every scriptable
  method (built from the same wire API and `mcp:summary` annotations the MCP bridge uses).

> The Command Manual is generated — do not edit it in the wiki. To change a command's name,
> description or example, edit the vocabulary in `app/cmdline` in the
> [Oblikovati repository](https://github.com/Oblikovati/Oblikovati); the wiki rebuilds on the
> next merge to `develop`.
