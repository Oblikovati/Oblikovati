# Loft path modes

The published `loft-07` scenario creates and reopens a two-circle solid Loft.
The Rails list and shaded preview appear first. Center Line asks for its
source sketch, disables OK, and removes the transient preview. The third mode
also offers Placed Sections. Returning to Rails restores the saved section
list, preview, and enabled OK.
