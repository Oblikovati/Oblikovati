# Reuse a visible consumed sketch profile

The scenario opens the published part with a 20 mm extrusion and reveals
the source sketch through its browser context menu. Selecting that sketch
in the browser supplies its single closed region to Extrude. Accepting
the preview produces two solid bodies. The shared sketch moves to the
top level of the browser, and both features reference its one sketch ID.

[Wayland JUnit](wayland/junit.xml) and [X11 JUnit](x11/junit.xml)
record the published scenario. The pinned scenario revision predates
this shared profile scenario.
