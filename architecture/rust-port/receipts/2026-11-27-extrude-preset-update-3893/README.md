# Save, update, and rename an Extrude preset

The Extrude example passed all ten published steps on Wayland and X11.
It creates a preset at 10 mm, saves an updated distance of 8 mm, and
changes the draft to 6 mm before reselecting the preset. The panel and
preview return to 8 mm. After Rename Current, the menu offers the new
name and reselecting it restores the same 8 mm preview. The part has
zero committed features throughout.

Each report includes the Revolve example. That example stops at its
unbound command setup and remains open.
