# Home with the published Recent profile

The first current Home Recent Documents scenario passed all ten steps.
An isolated profile loaded the five Recent entries from disposable
copies of the published package. Part23 opened with its saved Sketch1
in edit. Choosing Home from View Switch showed the navigation rail and
Recent controls, and kept Part23 available on its document tab.

The run used base revision `e1147f19d66cf1463bd6a88684e9e0b14af904fa`, the published-profile
bindings, and existing local GUI filesystem, opening and saving edits.
The desktop ran on Linux X11 with Xvfb, Openbox and Vulkan Lavapipe.
The [input hashes](current-inputs.sha256) matched the isolated copies.
Strict build and runtime provenance remains open under #3978. See
the [Cucumber report](cucumber.json).
