# Current native Model Browser

Ninety-six dependency-ready cases passed 1,305 steps on Linux X11 with
Xvfb, Openbox and Vulkan Lavapipe. The current runs verified camera
autosave in the empty Part and canceling a staged `d0` column and value.
The final cases covered annotation scale, view renaming, visibility
restore, suppression switching, expressions, member row cancellation,
and feature creation in one model-state member.

The [parameter interface](case-90/cucumber.json),
[second parameter](case-96/cucumber.json),
[active-member values](case-97/cucumber.json), and
[context menus](case-98/cucumber.json) cases require extrusion-owned
angular parameter `d1`. Their reports stop at the missing taper setup.
The application and kernel issues are open.
