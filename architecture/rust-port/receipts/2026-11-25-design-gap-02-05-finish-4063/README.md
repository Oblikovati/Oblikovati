# Extrude property controls

Native verification used Xvfb, Openbox, and Vulkan Lavapipe. The build included
the working dock and browser styling and the existing file-system edits.

- Collapsing Behavior reduced the floating window height by more than 25 px.
- With a rectangular profile and an 8 mm distance, the Preview eye hid and
  restored the transient model.
- Apply & Create New committed one feature and opened a fresh draft.
  Cancel then closed the draft. [Captured properties](extrude-profile-and-actions.png)
- The short-panel regression retained OK and Cancel after resizing. Starting
  Chamfer or Extrude closed the other command’s draft.
