# Enter in Extrude Properties

The published outline opens a valid extrusion, verifies the checked
state of **Single ENTER to finish command** in Advanced Settings, and
types 8 mm in the active distance field. With the setting checked,
Enter commits Extrusion1 and closes the panel. With it unchecked, Enter
leaves the panel open with a valid 8 mm preview and no committed
feature. The setting defaults to checked in a new desktop session.

Both examples and all eight steps passed on each native backend.
