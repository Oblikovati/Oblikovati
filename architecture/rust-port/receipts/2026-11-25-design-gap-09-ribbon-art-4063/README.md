# Ribbon command artwork

Normal Sketch draws icons for Delete, Rectangular, Circular, and Center
Point. Edit Theme uses the icon button in Normal View. The Modify flyout
loads the Bend Part and Copy Object artwork from the design handoff. Measure and Open Team
Web use the theme's icon colors.

The GUI draw-packet checks found the Sketch and Tools icons at the intended
sizes. They verified the Light and Dark work-axis textures differ and the
disabled glyph is composited at 45% opacity in both themes. On X11 the
Light View check also opened the Theme editor from the ribbon.
