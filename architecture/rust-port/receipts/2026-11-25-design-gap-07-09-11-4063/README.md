# Home lockup and ribbon artwork

The native desktop used Xvfb, Openbox, and Vulkan Lavapipe. The build included
working property and browser updates and existing local file-system edits.

- The canonical catalog test rasterized all 245 listed production SVGs with
  the shipped renderer in Dark, Light, and High Contrast. Each render
  produced visible pixels.
- The native test identified the sampled icons from image quads next to
  their visible captions in Manage, View, Assemble, and Place Views.
  [Manage](manage-command-icons.png) · [Assembly](assembly-command-icons.png) · [Drawing](drawing-command-icons.png)
- The native compact Create key-tip test opened Extrude from the densified
  ribbon using the existing keyboard route.
- The Home wordmarks retain the handoff art and outline the lettering with
  the bundled Inter and JetBrains Mono fonts for the vector renderer.
