# Remove one Extrude preset

The Extrude example passed all seven published steps on each Linux
desktop. It saves separate 8 mm and 6 mm presets, selects the first,
and chooses Delete Current. The deleted name disappears from the list.
The remaining preset still previews 6 mm when selected. Properties
stays open and the document has zero committed features and undo steps.

The reports also contain the Revolve example, which stops at its
unbound command setup.
