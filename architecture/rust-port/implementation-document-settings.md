# Document Settings

Tools opens Document Settings for the active document. Standard is selected
on each open. For Parts and Sheet Metal documents it displays the current
material and appearance assignments from the model browser. The values are
read-only here.

Units retains the staged length, angle, mass, time, display format and
precision controls. Apply submits the draft through the typed document-units
operation. Cancel discards it. A clean dialog offers Close, with Cancel and
Apply disabled. Changing the active document closes its settings and clears
the draft.

Sketch, Modeling, Bill of Materials and Default Tolerance are visible and
unavailable. The [native receipt](receipts/2026-11-24-document-settings-3856/README.md)
covers the Standard page, the action buttons and entry through the full and
compacted Tools ribbon.
