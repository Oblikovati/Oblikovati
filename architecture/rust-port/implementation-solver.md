# Shared constraint solver — partial R2

Tracking: [#3698](https://github.com/Oblikovati/Oblikovati/issues/3698).
The new `oblikovati-solve` crate starts the shared numerical core required by
[ADR-0006](../decisions/ADR-0006-parameters-and-constraints.md). It has no runtime
dependencies and owns no model, kernel, file, or window state. The derivative,
evaluation, QR, structure, and bounded nonlinear layers are now ported. Model
residual libraries, sketches, and assembly placement remain unimplemented.

## Scalar automatic differentiation

`DualNumber` owns a finite value and its gradient in seeded-variable order.
Constants have an empty gradient. Arithmetic propagates partials without changing
inputs. Two seeded operands must have equal dimensions; constants can combine
with any seeded dimension. Invalid indices, non-finite inputs, undefined domains,
and non-finite output values or partials return `DerivativeError`.

The port includes sum, difference, product, quotient, negation, constant offset
and scale, square root, hypot, absolute value, atan2, sine, and cosine. As in Go,
square root, hypot, absolute value, and atan2 use a zero-gradient convention at
zero. These are explicit conventions at nondifferentiable/undefined points, not
claims of mathematical derivatives there. Later solver diagnostics must handle
those degeneracies; a zero row does not by itself prove a satisfied constraint.

The quotient rule avoids unnecessary intermediate multiplication. Atan2 scales
its operands before computing partials, avoiding both squared-coordinate and
norm overflow. Representable angle/quotient derivatives are tested at scales
`1e-200`, `1e200`, and `f64::MAX`; unrepresentable results are refused.

## Evidence

The committed `go-ad.tsv` fixture was generated by `solve/ad` at Go baseline
`aa8297d1b0ac33c024f19e54821536d76e8a447a` with seeds `(3, 4)`. Tests compare each
primitive's value and gradient against it and independently evaluate central
differences over scalar formulas. Separate analytic tests cover a circle residual,
unit seeds, constant mixing, immutable inputs, negative absolute values, zero
conventions, invalid dimensions/seeds/domains, and extreme scales.

This proves the scalar derivative layer only. It does not prove convergence,
constraint classification, fully constrained sketches, or kernel integration.
The normal workspace gate discovers and checks the solver crate with all other
Rust crates; no separate or skipped solver test path was introduced.

## Derivative vectors — partial R2

Tracking: [#3699](https://github.com/Oblikovati/Oblikovati/issues/3699).
`DualVector<N>` owns fixed-size components with one compatible seeded dimension;
constants may mix with seeded components. One implementation supplies component
addition/subtraction, fixed and varying scaling, dot products, and lengths for
both planar and spatial residuals. Specialized cross products return a scalar
in 2D and a vector in 3D. These floating residual operations are not exact
predicates for kernel topology.

Lengths use chained `hypot` rather than squared components. This retains
representable norms and their partials at very small and very large coordinate
scales. The zero-vector convention remains zero partials. Operations return new
owned values; incompatible dimensions or non-finite results fail without input
mutation. The previous Go vector layer's unchecked dimension mixing is refused.

Tests cover Go reference values, analytic dot/cross/length derivatives, a six-
variable spatial cross product against independent central differences, constant
and seeded scaling, immutable inputs, dimension mismatches, zero vectors, and
norm scale sweeps from `1e-200` to `1e200`. The nonlinear solver and model residual
libraries remain pending; vector primitives alone do not establish sketch DOF.

## Residual evaluation and Jacobian assembly — partial R2

Tracking: [#3700](https://github.com/Oblikovati/Oblikovati/issues/3700).
`ResidualSource` evaluates equations over immutable dual-number inputs.
`ResidualBlock` declares local variable references and a stable equation count.
The evaluator validates every reference before calling any source, seeds the
global input once, and passes owned local views in each source's declared order.
Repeated references share the same seeded column, so their contributions combine
through automatic differentiation without pointer identities or live mutation.

Values and Jacobian rows come from the same evaluation. Rows follow source and
local equation order; columns follow the caller's global variable order. Constant
rows expand to zero partials. The result retains source row ranges for later
conflict/redundancy diagnostics, and a variable count even when there are no rows.

Invalid/non-finite input, wrong equation counts, incompatible gradient widths,
and source domain/arithmetic failures return named errors. No partial evaluation
is published. Production evaluation requires derivative-aware sources; there is
no implicit finite-difference fallback. Non-differentiable legacy sources still
need adaptation before they can use this boundary.

Tests cover the Go gap and repeated-variable cases, multiple equations per
source, reordered/shared columns, constants, empty systems, deterministic repeat
evaluation, exactly one call per source, input preservation, validation before
callbacks, and error provenance. This is a dense derivative representation;
nonlinear iteration, numerical rank, and model residual definitions remain pending.

## Shared column-pivoted QR — partial R2

Tracking: [#3701](https://github.com/Oblikovati/Oblikovati/issues/3701).
`DenseMatrix` validates finite rectangular input, including explicit empty axes.
`ColumnPivotedQr` uses one Householder factorization for numerical rank and
full-column-rank least-squares solving. This replaces the two overlapping QR
paths in the Go port; normal equations are not formed. Column permutations map
solutions back to caller order, and equal candidate norms retain current order.

The rank threshold is an explicit finite relative tolerance strictly between
zero and one. Global matrix scaling, hypot-based norms, normalized reflectors,
and scaled projections avoid avoidable square/projection overflow. Reflector
updates subtract the projection twice instead of forming a potentially
unrepresentable doubled value. Rank-deficient or wide least-squares systems,
invalid shapes/tolerances, and non-finite arithmetic return named errors.
Inputs remain unchanged and the factorization can solve multiple right-hand sides.

Six tests cover the Go square and overdetermined fixtures, residual orthogonality,
original column ordering, rank deficiency, empty axes, invalid input, deterministic
ties, scale sweeps from `1e-200` to `1e200`, and a right-hand side containing both
`f64::MAX` and `1e-300`. Jacobian `matrix.rank.compute` independently certified
exact ranks 2 and 3 for the rectangular and square fixtures. It also certified
rank 2 for `[[1,1],[1,1+10^-12]]`; the floating test intentionally reports rank 1
at tolerance `1e-9` and rank 2 at `1e-14`. Exact rank and numerical working rank
are distinct results. These checks do not certify arbitrary conditioning.

Residual row normalization, DOF policy, damping, nonlinear iteration, and conflict
attribution still need integration with the evaluation boundary.

## Constraint structure and redundancy — partial R2

Tracking: [#3702](https://github.com/Oblikovati/Oblikovati/issues/3702).
`analyze_structure` consumes one captured residual evaluation and reports variable
and equation counts, numerical rank, DOF, dependent equation count, and the Go
structural status. Dependent rows take precedence over free variables when naming
an over-constrained system. These are local Jacobian results, independent from
residual satisfaction and nonlinear convergence.

Each nonzero row is normalized through its largest component and a scaled norm.
There is no absolute small-row cutoff. This handles rows at `1e-300`, `1e300`, and
`f64::MAX` without overflowing a norm or reciprocal. Zero rows remain zero.
The caller supplies the relative QR tolerance; even empty systems validate it.

`redundant_sources` removes each nonempty source's complete row range in turn and
compares rank against the full system. Results retain source order and represent
alternative individual removals, not a batch deletion instruction. A source with
both essential and dependent equations is not removable if its removal loses
rank. Empty sources are omitted rather than reported as useful repairs.
The same stored Jacobian is used throughout; source callbacks never rerun.

Tests cover Go status precedence, duplicate and multi-equation sources, row-scale
sweeps, zero/empty systems, near-dependency tolerance, unchanged evaluations, and
single-pass source calls. Convergence metrics, conflict severity, and nonlinear
iteration remain separate work.

## Bounded nonlinear iteration — partial R2

Tracking: [#3703](https://github.com/Oblikovati/Oblikovati/issues/3703).
`solve_constraints` accepts a warm start, residual blocks, explicit numerical
options, and an injected cancellation callback. It returns owned final accepted
values, their captured evaluation, local structure, relative residual severity,
unsatisfied source indices, and a separate termination reason. It never writes
caller values or publishes rejected trial state. Iterations count accepted steps;
trial steps include rejected attempts. Both limits and the damping ceiling bound
work. Cancellation is polled before iterations and trials; it does not interrupt
an individual source callback or QR factorization.

One Levenberg–Marquardt path augments the scaled Jacobian with column-norm damping
and solves through the shared pivoted Householder QR. No normal equations or
finite differences are formed. Initial damping, the finite trust budget, and the
Moré/Nielsen acceptance schedule follow the Go solver. Norms and gain ratios avoid
squaring large residuals. Trial merit uses the current point's fixed row weights,
so changes in derivatives cannot manufacture an apparent residual decrease.

Iteration now uses the same unit-row policy as rank analysis. Nonzero residuals
are divided by their Jacobian row norm and the initial maximum absolute variable
value (one for an all-zero warm start). Variables step in these normalized units.
This extends the Go convergence weighting into the numerical step and merit;
Go used raw residuals there. Opposite row/coordinate units are combined before
division to avoid intermediate overflow or underflow. Zero rows retain their
raw residual scaled by the initial variable magnitude. A zero-variable system
must satisfy its equations; it is not automatically converged as in legacy Go.
These are local numerical criteria, not a kernel geometric tolerance certificate.
Callers remain responsible for meaningful variable units and residual domains.

Convergence, iteration limit, stall, and cancellation retain a valid final
accepted evaluation. Initial evaluation failures and malformed residual
contracts return errors. Numerical/domain failures during trials are rejected
within the same bounded damping path and retain the last such error for
inspection. Unsatisfied sources use final stored rows without callback replay,
ordered by descending severity and then source index. Structural redundancy is
independent from convergence: a consistent redundant system can converge.

Tests compare roots and DOF with `go-nonlinear.tsv`, generated at Go baseline
`aa8297d1b0ac33c024f19e54821536d76e8a447a`. Analytic checks include a squared root,
a free gap, duplicate and inconsistent constraints, constant/empty systems,
a stationary singular failure, rejected square-root domains, bounded trials,
iteration limits, cancellation, shape violations, immutable inputs and repeated
results. The Go mixed-length regression (1000 and 0.01 in one system) passes the
general path. Coordinate scales `1e-100` through `1e100` and equation coefficients
`1e-200` through `1e200` retain roots. Direct arithmetic tests cover opposite units,
nonrepresentable trial coordinates and the damping gain schedule. The complete
Go `./solve` test suite also passes as reference evidence.

This establishes the shared numerical iteration boundary. Fully constrained
sketches, assembly pose normalization, mobility, feature health integration,
SolveSpace model parity and interactive rendering remain migration work.
