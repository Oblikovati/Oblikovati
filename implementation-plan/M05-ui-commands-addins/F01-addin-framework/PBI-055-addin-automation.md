# PBI-055 — Add-in automation object exposure

**Milestone:** M05 Application UI, Commands, Interaction & Add-in Platform  ·  **Feature:** F01 Add-in Framework

## Goal

Let an add-in expose an automation object so other add-ins/scripts can call it.

## Scope / work

- `AddInAutomation` exposure & retrieval.
- Inter-add-in calls.

## API contracts (interfaces / enums / collections)

## Acceptance criteria
