# File menu

With a part active, selecting File opens an application menu over the upper-left portion of the workspace. A vertical list contains New, Open, Save, Save As, Export, Share, Manage, document properties, Print and Close. A recent-documents region appears to the right, and application options and an exit control appear along the bottom. The active workspace remains visible around the menu. Some actions show disclosure indicators; recent entries show pin controls.

Pressing Escape closes the menu and returns to the same active part workspace. The visible recent list depends on session history. Subcommand behavior, pinning, sorting and exit were not established in this capture.

See [file-menu.feature](file-menu.feature) for the observed scenarios and [VISUAL.md](VISUAL.md) for the layout, colors and an independent icon brief.

Clicking an empty area of the viewport outside the open menu also dismisses the menu and leaves the same part active.

The same top-level command labels and recent-documents region were visible with a drawing active. The drawing sheet remained visible around the panel, and Escape returned to that drawing. This comparison does not establish whether the commands or submenus behave identically across document types.
