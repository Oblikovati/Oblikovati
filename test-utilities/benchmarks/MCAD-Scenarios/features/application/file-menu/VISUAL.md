# File menu: visual observations

- Trigger: select File while a part is open.
- Layout: a panel opens from the upper-left corner. A vertical action list occupies its left side and a wider recent-documents region occupies the right. Application options and exit controls sit at the bottom. The workspace remains visible around the panel.
- Feedback: actions have icons and labels; some show a right-pointing disclosure indicator. Recent items have individual pin controls. Their behavior was not exercised.
- Color: dark blue-grey menu background, light text, and a contrasting File tab in the observed theme.
- Original icon brief: use a newly designed folded sheet paired with a small grid for the file menu, avoiding the source icon geometry.
- Limits: the recent list is session-specific; no claims are made about item ordering, pinning or menu subcommands.
