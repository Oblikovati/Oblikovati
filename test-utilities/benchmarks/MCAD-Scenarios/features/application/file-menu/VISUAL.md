# File menu: visual observations

- Trigger: select File while a part is open.
- Layout: a panel opens from the upper-left corner. A vertical action list occupies its left side and a wider recent-documents region occupies the right. Application options and exit controls sit at the bottom. The workspace remains visible around the panel.
- Feedback: actions have icons and labels; some show a right-pointing disclosure indicator. Recent items have individual pin controls. Their behavior was not exercised.
- Color: dark blue-grey menu background, light text, and a contrasting File tab in the observed theme.
- Original icon brief: use a newly designed folded sheet paired with a small grid for the file menu, avoiding the source icon geometry.
- Limits: the recent list is session-specific; no claims are made about item ordering, pinning or menu subcommands.

## Dismiss with Escape

- Trigger: press Escape while the File menu is open over an active part.
- Feedback: the menu and recent-document panel disappear, revealing the same active workspace.
- Limits: the sequence did not activate a menu command or change the part.

## Dismiss by clicking outside

- Trigger: click an empty viewport area outside the open File menu.
- Feedback: the menu and recent-document region disappear and the same part remains active.
- Limit: this was observed on an empty viewport.

## File menu over a drawing

- Context: an active drawing shows a light sheet, border and title block.
- Trigger and feedback: selecting File opens the same two-column menu over the upper left, with the drawing sheet visible around it. The visible top-level labels match those observed with a part. Escape closes the menu and leaves the drawing active.
- Limit: individual menu commands and submenus were not invoked in this drawing.

[File-menu icon](file-menu-icon.svg) is an original colored folded-page and grid design created from the brief; it is not extracted from a source screenshot.

## Recent-document controls

- Context: File menu open with recent documents available.
- Layout: an ordering label with a disclosure marker and a separate small display control sit above a vertical list. Each visible row pairs a type symbol and name on the left with a pin symbol at the right.
- Meaning: the symbols distinguish document entries and expose pin affordances; behavior of those controls was not established.
- Color: light labels and muted symbols on a blue-grey panel, with small blue accents on some document-type symbols.
