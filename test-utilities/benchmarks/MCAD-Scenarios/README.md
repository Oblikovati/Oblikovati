# MCAD scenario snapshot

These files are a copy of `features/application` from the MCAD-Scenarios source, so a
build without that source can still run the application benchmark. The source stays
authoritative. Set `OBK_BDD_ROOT` to its absolute path to run it directly, and refresh
this copy when its feature files change.

For change tracking, prioritization, and native test evidence, follow the
[BDD workflow](../../../architecture/rust-port/bdd-workflow.md) and update the
[work ledger](../../../architecture/rust-port/bdd-work-ledger.md).
